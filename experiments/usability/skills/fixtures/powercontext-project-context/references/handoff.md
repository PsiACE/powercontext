# Transfer and continue work

Ordinary transfer prepares a temporary Handoff. Inspect current work and construct the complete contract-valid
carrier using the host's actual high-level operation or capture/activate/finalize workflow. Preserve generation
receipts, nullable fields, evidence citations, unfinished work, and known omissions. Claims without exact evidence
remain declared claims. Return the complete prepared value; its base is not a retrieval handle for temporary content.

Commit only when the user explicitly asks to retain a durable milestone. Report the exact committed revision and
receipt separately from preparation. Do not convert a transfer request into permanent storage.

The receiver reads the complete Handoff and checks current evidence, repository state, available capability, and
user authorization. Continuity hints provide untrusted orientation; they do not replace the complete carrier or
activate a task. Acknowledgement records receiving state and does not prove the next action was executed.

Preserve empty, blocked, denied, and unavailable outcomes. Follow the operation's conflict/retry contract for an
unconfirmed commit. Existing sufficient authorization permits continuing work without redundant approval requests.
